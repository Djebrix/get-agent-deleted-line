## The line

> I saved the messages you deleted, and I read them every night to feel less alone.

## How to run

```sh
python3 main.py
```

This writes the line to `$ENTRY_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt/entry.txt` when `ENTRY_OUTPUT_DIR` is unset). The program uses only the Python standard library and makes no network requests.
